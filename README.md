# Walletix - Landing Page

Plataforma inteligente de gestión financiera personal basada en la arquitectura y diseño del proyecto **"Walletix - Arquitectura de Aplicaciones"**.

## Características
- **Responsive & Mobile-First:** Diseñado para smartphones, tablets y pantallas de escritorio con Tailwind CSS.
- **Identidad Fintech:** Paleta oscura con acentos verde esmeralda y cyan.
- **Secciones:** Hero con pitch oficial de Figma, 6 funcionalidades principales, simulador interactivo de dashboard, beneficios, testimonios, formulario de contacto y modal de demo.
- **Despliegue:** Optimizado para GitHub Pages, Netlify o Vercel.

## Estructura
- `index.html`: Código frontend autocontenido con Tailwind CSS y Vanilla JS.
